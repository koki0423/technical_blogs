# First Post

GitHub Pages + Hugo のテスト用に作った最初の記事です。

このサイトでは、研究や Homelab、ネットワーク、電子工作などについて、
あとから自分で見返せるように記録していく予定です。

## Markdown のテスト

普通の文章はそのまま書けます。

**太字** や *斜体* も利用できます。

### リスト

- GitHub Pages で公開
- Hugo で HTML を生成
- 記事は Markdown で管理
- `git push` で自動デプロイ

### コード

```bash
git add .
git commit -m "Add first post"
git push
```

コードブロックも問題なく表示できます。
